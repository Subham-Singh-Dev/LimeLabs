=======================

Included:
- index.html
- services.html
- solutions.html
- industries.html
- work.html
- about.html
- blog.html
- careers.html
- contact.html
- privacy.html
- terms.html
- services/ (6 detailed service pages)
- styles.css
- script.js
- assets/limelabs-logo.jpg

Run locally:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Use Live Server, or run: python -m http.server 8000
4. Open http://localhost:8000

Before production:
- Replace placeholder project content with real case studies and screenshots.
- Connect the contact form in contact.html to your backend/email service.
- Replace demo phone/email/address if needed.
- Add your real team photos and social links.
- Add real legal/company details.
